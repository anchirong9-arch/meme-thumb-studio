# 짤 썸네일 스튜디오

짤 이미지에 **굵은 흰 글씨 + 두꺼운 검은 테두리** 문구 띠를 얹고, **유튜브 커뮤니티 피드**와 **틱톡 피드**에서 실제로 어떻게 보이는지 확인한 뒤 **1080px PNG**로 저장하는 도구입니다.

- 주소: **https://anchirong9-arch.github.io/meme-thumb-studio/**
- 빌드 없음 — `index.html` + `style.css` + `app.js` 만으로 동작합니다.

## 쓰는 법

1. 이미지를 **끌어다 놓기 / 이미지 선택 / Ctrl+V** 중 아무 방법으로 넣습니다.
2. **띠 문구**에 2~3줄을 입력하고, 글자 크기·줄 간격·띠 두께·띠 투명도·글자 테두리·이미지 확대를 슬라이더로 맞춥니다.
   - 캔버스를 드래그하면 이미지 위치가 움직입니다(확대했을 때).
3. 위쪽 **1:1 / 4:5 / 9:16**으로 출력 비율을 고릅니다.
   - 유튜브 커뮤니티 = **1:1**, 틱톡 = **9:16** 권장.
4. 오른쪽 미리보기 탭에서 **유튜브 커뮤니티 / 틱톡 피드**를 전환해 확인합니다.
   - 미리보기 위 검수 줄이 비율·글자 길이·**하단 띠와 틱톡 캡션 겹침**을 알려 줍니다.
   - 틱톡 탭의 **가림 영역 보기**를 누르면 캡션·아이콘이 덮는 구간이 빨간 빗금으로 표시됩니다.
5. **PNG 다운로드** — 1080px 고해상도로 저장됩니다. 파일명은 `meme-thumb-YYYYMMDD-HHMM.png`.

## 동작 메모

- 모든 그리기는 Canvas에서 한 번에 처리하므로 화면 미리보기와 저장 PNG가 같습니다.
- 문구가 한 줄 폭(92%)을 넘으면 자동으로 줄여서 밖으로 나가지 않습니다.
- 문구·슬라이더·캡션·비율 설정은 브라우저에 저장되어 다음에 열면 그대로 이어집니다(이미지는 저장하지 않음).
- 휴대폰·PC 모두 반응형. 휴대폰에서는 편집기 아래에 미리보기가 오고 탭은 붙어 따라옵니다.
