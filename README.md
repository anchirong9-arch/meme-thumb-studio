# 짤 썸네일 스튜디오

짤 썸네일에 문구 띠를 얹고, 상품 후기 카드까지 만들고, **유튜브 커뮤니티 피드**와 **틱톡 피드**에서 실제로 어떻게 보이는지 확인한 뒤 **1080px PNG**로 저장하는 웹 도구입니다.

- 주소: **https://anchirong9-arch.github.io/meme-thumb-studio/**
- 빌드 없음 — `index.html` + `style.css` + `app.js` 만으로 동작합니다.

## 1. 짤 썸네일 탭

1. 이미지를 **끌어다 놓기 / 이미지 선택 / Ctrl+V** 중 아무 방법으로 넣습니다.
2. **띠 문구**에 2~3줄을 입력합니다. (1줄·2줄·3줄 예시 버튼)
3. 꾸미기
   - 글자 크기, 줄 간격, 띠 두께, 띠 투명도, 테두리 두께 슬라이더
   - **글자 색 / 테두리 색 / 띠 색** 색상 선택
   - **띠 위치: 하단 / 상단**, 글자 정렬 왼쪽·가운데·오른쪽
   - 이미지 확대(100~320%) 후 캔버스를 드래그해 위치 조정
4. 위쪽 **1:1 / 4:5 / 9:16** 비율 선택 — 유튜브 커뮤니티는 **1:1**, 틱톡은 **9:16** 권장.
5. **PNG 다운로드** → `meme-thumb-YYYYMMDD-HHMM.png`

## 2. 상품 후기 카드 탭

- **제목 프리셋 5종** (누르면 바로 적용, 직접 입력도 가능)
  - 이 가격 맞나 싶은 가성비 꿀템
  - 1만 원 이하인데 뽕 뽑는 제품
  - 솔직히 이 가격이면 무조건 쟁이는 템
  - 좋은데 저평가 받는 제품 甲
  - 가성비로 이미 정평 난 박리다매템
- 상품 사진 업로드, 상품명, 정가·할인가(할인율 배지 자동 계산), **형광펜 색**, 가격 색
- 후기 본문은 구어체 존댓말로, 자주 쓰는 문장 3종 버튼으로 한 번에 붙일 수 있습니다.
- 하단에 `[광고 포함] 쿠팡 파트너스 …` 표기가 자동으로 들어갑니다.
- 카드 기본 비율은 **4:5(1080×1350)**, 저장 파일명은 `review-card-YYYYMMDD-HHMM.png`

## 3. 4:5 일괄 여백 변환 탭

- 사진을 **최대 20장**까지 한 번에 **끌어다 놓기 / 선택 / Ctrl+V**로 올립니다.
- 올린 사진마다 비율 그대로(contain) 캔버스 가운데에 놓고, 남는 곳을 **여백 색**(기본 흰색)으로 채웁니다.
- **출력 비율**: `4:5 (1080×1350)` · `1:1 (1080×1080)` · `9:16 (1080×1920)` · `16:9 (1920×1080)`
- **사진을 누르면 크게 보기 + 모자이크·가리기 편집**이 열립니다.
  - **모자이크**(픽셀화) / **흰색 가리기** / **검은색 가리기** 중 고르고, 사진 위를 드래그해 영역을 지정합니다.
  - **모자이크 강도** 슬라이더는 마지막으로 그린 모자이크에도 바로 적용됩니다.
  - **되돌리기**(마지막 영역 취소) / **원본 복구**(편집 전부 취소)
  - 편집 창 안에서도 출력 비율을 바꿔 바로 확인할 수 있습니다.
- 저장: 카드의 **PNG**(한 장씩 `이름-4x5.png` 형태) 또는 **모두 ZIP으로 한 번에 다운로드**(`4x5-batch-YYYYMMDD-HHMM.zip`).
  - ZIP은 JSZip 없이 순수 JS로 만드는 무압축 ZIP이라 인터넷이 느려도 바로 됩니다.
- 모자이크·가리기 편집 결과는 그대로 변환·ZIP에 반영됩니다.

## 4. 피드 미리보기

- **유튜브 커뮤니티 탭**: 다른 게시물 사이에 내 게시물이 들어간 모바일 화면. 제목/캡션과 썸네일이 어떻게 붙는지 확인.
- **틱톡 피드 탭**: 9:16 세로 화면에 캡션·아이콘·하단 메뉴가 겹친 모습 그대로.
  - **가림 영역 보기**를 누르면 캡션·아이콘이 덮는 구간이 빨간 빗금으로 표시됩니다.
- 미리보기 위 검수 줄이 자동으로 알려 줍니다
  - 비율이 피드와 안 맞는지
  - 하단 띠가 틱톡 캡션 자리와 겹치는지
  - 문구가 너무 길거나 3줄을 넘는지
  - 할인가가 정가보다 큰지, 할인율이 몇 %인지

## 동작 메모

- 모든 그리기는 Canvas 한 번으로 처리하므로 화면 미리보기와 저장 PNG가 같습니다.
- 문구가 한 줄 폭(92%)을 넘으면 자동으로 줄여서 밖으로 나가지 않습니다.
- 문구·색·슬라이더·캡션·비율·카드 내용은 브라우저에 저장되어 다음에 열면 그대로 이어집니다(이미지는 저장하지 않음).
- 일괄 변환 탭의 사진·편집 내용은 저장하지 않습니다. 새로고침하면 비워집니다.
- 휴대폰·PC 모두 반응형. 휴대폰에서는 편집기 아래에 미리보기가 오고 탭은 붙어 따라옵니다.
